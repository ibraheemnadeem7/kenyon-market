# Kenyon Market

A Kenyon-only move-out marketplace: snap a photo, get a listing, and watch the price drop on a schedule until it turns free. Built for IPHS 484. Every listing, view and sale is logged (anonymized) for a time-to-sale study.

## Run it locally

```
npm install
npm run dev
```

Then open http://localhost:3000.
